# TRACKQUEST

Finish more music. Track every song from first idea to release — and level up your artist along the way.

Single-player, local-first web app. No accounts, no server. State persists in IndexedDB.

## Stack

- Vite + React + TypeScript
- Zustand + idb-keyval
- Handwritten CSS (prototype visual system)
- Canvas sprite engine

## Develop

```bash
npm install
npm run dev
npm test
npm run build
```
